# 순정 SD_PRO 파일시스템 백업

새 기기(SD Pro V1.0.6)의 LittleFS를 통째로 옮겨온 것입니다. 69개 파일,
1,486,248 바이트, 크기 전부 대조 일치.

## 왜 이 폴더가 필요했나

순정 웹 UI에는 파일을 **내려받는 경로가 아예 없습니다.** 업로드와 목록만
있고, `/edit`, `/list`, `/download`, `/file`은 물론 `/ico/01d.jpg` 같은 직접
경로까지 전부 404입니다. 그래서 순정 파일시스템을 마운트할 수 있는 펌웨어를
직접 만들어(`src/bootsafe.cpp`, 4m3m 레이아웃) 올린 뒤에야 꺼낼 수 있었습니다.

4m2m 레이아웃의 본 펌웨어를 올리면 이 파일시스템은 더 이상 보이지 않습니다.
이 백업이 유일한 사본입니다.

## 날씨 아이콘 (요청 사항)

세 세트가 용도별로 다른 크기입니다. OpenWeatherMap 아이콘 코드를 파일명으로 씁니다.

| 폴더 | 개수 | 픽셀 | 쓰임 |
| --- | --- | --- | --- |
| `ico/` | 13 | 65x46 (습도·온도만 30x30) | 표준 |
| `ico2/` | 11 | 45x32 | 작은 표시 |
| `weather/` | 11 | 240x142 | 화면 전체 폭 배너 |

코드: `01d` 맑음(낮), `01n` 맑음(밤), `02d`/`02n` 구름조금, `03d` 구름많음,
`04d` 흐림, `09d` 소나기, `10d` 비, `11d` 뇌우, `13d` 눈, `50d` 안개.
밤 아이콘은 `01n`, `02n` 둘뿐이고 나머지는 낮 아이콘을 함께 씁니다.

`ICONS-preview.png`가 세 세트를 한눈에 보여줍니다.

## 그 밖에 들어 있는 것

- `*.vlw` — TFT_eSPI 폰트 5종. `NotoSansKR18.vlw`(139KB)는 한글 글리프를
  담고 있어 그대로 쓸 수 있습니다.
- `FlipClock/0-9.gif` — 플립 시계 숫자 애니메이션
- `0-4.gif` — 기본 테마 애니메이션
- `index.html`, `javascript.js`, `style.css` 등 순정 웹 UI 일체
- `photo/` — 출하 시 들어 있던 사진과 GIF

민감한 값은 들어 있지 않습니다. WiFi 비밀번호와 API 키는 파일이 아니라
`/config` 응답에만 있어서 이 백업에 포함되지 않았습니다.
